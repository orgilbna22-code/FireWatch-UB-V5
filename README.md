# FireWatch UB V5

A modern GIS-based urban fire risk monitoring platform for Ulaanbaatar, Mongolia.

## Technology

- React
- TypeScript
- Vite
- MapLibre GL
- deck.gl
- Node.js
- Express

## Features

- Interactive GIS map
- Fire risk visualization
- Weather monitoring
- District and khoroo analytics
- Incident management
- Administrative dashboard
